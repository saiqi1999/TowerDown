# 九、BitMask

给四个方向分配 bit：

```
TOP    = 0001 = 1

RIGHT  = 0010 = 2

BOTTOM = 0100 = 4

LEFT   = 1000 = 8
```

例如：

当前 Dirt 周围：

```
       Dirt

Grass  Dirt  Dirt

       Dirt
```

那么：

```
Top    = 1
Right  = 1
Bottom = 1
Left   = 0
```

Mask：

```
0111
```

即：

```
7
```
